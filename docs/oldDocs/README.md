# Historical documentation archive

This folder preserves superseded plans, completed rollout notes, old build guides, standalone visual
prototypes, generic prompt guidance, and implementation references that previously lived at the top
of `docs/`.

These files are historical evidence, not current product requirements. Their status lines describe
the moment when they were written and may no longer match the app. Links inside archived files are
preserved where practical, but some point to files or source layouts that no longer exist.

Use the current documentation index at [`../README.md`](../README.md) for the implemented lesson
plan, application setup, code boundaries, and authoritative workstation rules.
