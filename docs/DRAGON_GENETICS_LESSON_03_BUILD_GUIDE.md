# Dragon Genetics Lesson 3: Where Do Genes Live?

Lesson 3 uses one shared investigation in both story paths. Arena students trace information for an arena-dragon trait; Mini Show students trace information for a show-dragon trait. The biological organization and lesson questions are identical.

## Investigation structure

Students load an example dragon and freely move among these nested scales:

`dragon → body cell → nucleus → chromosome set → chromosome → gene locus`

They can select different chromosomes and gene loci, move backward or forward in magnification, and open the optional explanation for any scale. The investigation does not require a fixed sequence and does not decide when the student is finished.

## Workstation contract

- **Scientific goal:** locate a gene within a chromosome and chromosomes within a cell nucleus.
- **Manipulable evidence:** dragon specimen, magnification level, chromosome, and gene locus.
- **Visible consequence:** each selection remains connected as the microscope changes scale.
- **Student record:** four shared written responses on the lesson page.
- **Data source:** the local account genetics library, including foundation and device-saved dragons; Firebase is not required.

The teacher-owned lesson record is in `src/app/features/dragon-genetics/lesson-plan/dragon-lesson-plan.models.ts` and remains editable at `/teacher/lesson-plan`.
